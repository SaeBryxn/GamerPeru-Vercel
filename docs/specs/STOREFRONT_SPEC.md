# Storefront Specification
Required: Home, category, brand, search, PDP, cart drawer/full cart, checkout, account, order status, wishlist, referral attribution and help/policy pages.

Home: hero, launches, categories, best sellers, brands, editorial technology/product blocks, new arrivals, trust, SEO/editorial entry points and footer.

PDP: premium gallery + commerce controls + modular Product Story. Search-relevant text remains semantic HTML. Support variants, stock, delivery, technical attributes, box contents, FAQ and related products.

Discovery: category-aware filters, sorting, brand discovery, search and crawl-safe URLs. Mobile compositions are designed intentionally.
