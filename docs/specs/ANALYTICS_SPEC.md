# Analytics Specification
Commerce events: `view_item`, `view_item_list`, `search`, `select_item`, `add_to_cart`, `remove_from_cart`, `begin_checkout`, `payment_submitted`, `purchase`, `refund`.
Growth: `referral_visit`, `affiliate_click`, `affiliate_conversion`.
Metrics: revenue, orders, AOV, conversion/funnel, products/categories, stock, verification latency and fulfillment.
Use stable contracts, server-side truth for purchase/revenue and avoid unnecessary sensitive data.
