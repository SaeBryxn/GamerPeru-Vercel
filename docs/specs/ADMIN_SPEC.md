# Admin Specification

Admin modules: Dashboard; products/variants; Product Story/content; categories/brands; inventory; orders; payment verification; customers; promotions; review moderation foundation; affiliates/referrals/commissions; homepage/content; SEO fields; analytics; settings/audit.

Dashboard: revenue, orders, AOV, trends, best sellers, low stock, pending verification, fulfillment queue, customers, affiliate performance.

Security: role-based authorization with server-side enforcement and audit trails. Hidden UI is never authorization.
