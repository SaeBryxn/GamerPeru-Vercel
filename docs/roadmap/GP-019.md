## Scope

GP-019 receives an existing Order and an existing Payment record (status = 'UNPAID') created by GP-018 without recreating the payment shell (preserving Payment.order_id uniqueness). GP-019 owns: customer payment instruction presentation, interactive QR rendering, operation-code capture (PaymentSubmission.operation_code), optional voucher proof upload to private Cloudflare R2 storage, submission and resubmission UX, and transition into SUBMITTED / VERIFYING state (ADR-009).

## Out of Scope
