# GP-054 --- Actionable Admin Dashboard

## Status

CLOSED --- 2026-10-15 ([closure](./GP-054-CLOSURE.md)). Approved by the owner on 2026-10-15
after the review of the current `/admin` dashboard.

## Objective

Turn `/admin` from a read-only metrics report into the operator's starting point: what needs
attention now, one-click access to the main tasks, the state of the administrable home, and an
actionable list of products that are not ready, with every number linking to where it is
resolved.

## Why

The GP-023 dashboard shows real metrics but no number leads anywhere: pending orders, payments
to verify, out-of-stock SKUs and drafts are dead ends. Financial history is shown first while
work that needs action is below. The administrable home (GP-053) and per-product publish
readiness, which already exist, are not visible. The Product Story builder and `/admin/home`
set a higher bar for guidance and polish.

## Dependencies

GP-023 (Admin Dashboard), GP-024 (Admin Product Manager), GP-026 (Product Story Builder),
GP-027/GP-028 (Orders and Payments Admin), GP-053 (Administrable Homepage) --- all closed.

## Scope

1. **"Requiere tu atención"** at the top: payments to verify, orders to prepare, unpaid
   pending orders and out-of-stock active SKUs, each with a direct link to the filtered view,
   shown only for permissions the operator has.
2. **Quick actions** with wireframe cards (same language as stories and home) to `/admin/home`,
   `/admin/products`, `/admin/menu` and `/admin/orders`, filtered by permission.
3. **Home status** from `home_sections`: visible and hidden sections, sections never edited
   since the seed, empty image slots in visible sections, invalid content, link to
   `/admin/home`.
4. **Catalog health**: products with publish blockers or warnings (evaluated with the
   authoritative `evaluatePublishReadiness`), without a published story, or without gallery
   photos; each row links to the editor tab that resolves the first issue.
5. **Metrics** (financial, orders, payments, catalog, inventory) kept below with the period
   selector; each indicator links to its section.

## Out of Scope

- New metrics or analytics beyond the data already modeled.
- Editing from the dashboard (it links to the existing editors).
- Changes to permissions or roles.

## Requirements

- Reuse `evaluatePublishReadiness` and `readiness-guidance.ts`; no duplicated publish rules.
- New queries run in parallel inside `getAdminDashboardData`, only for authorized sections,
  with narrow projections; no per-product queries (no N+1).
- No fabricated or hardcoded figures (E2E E13 contract).
- Same admin design language and tokens, light and dark themes, keyboard and screen reader
  support.

## Acceptance Criteria

- Every attention item and metric with a destination is a link to the matching filtered view.
- Catalog health rows open the product editor on the tab of the first issue.
- Home status reflects `home_sections` and degrades to a clear message if the table is
  unavailable.
- Sections and links are hidden for operators without the corresponding permission.

## Testing / Validation

Unit tests for the new reader functions (permission gating, readiness aggregation, story and
gallery checks, home status), UI tests for links and empty states, `pnpm check`, `pnpm test:e2e`
in fixture mode; manual check of `/admin` in production (read-only).

## Functional DoD

Scope items delivered; acceptance criteria pass.

## Visual DoD

Consistent with the admin design system and the `/admin/home` and story builder guidance
pattern; light and dark; desktop and mobile.

## Performance DoD

All dashboard queries run concurrently; constant number of queries regardless of catalog size.

## SEO DoD

Not applicable (authenticated admin surface, not indexed).

## Security DoD

Server-side permission gating before any query; no new data exposed beyond what the linked
admin screens already show to the same permission.

## Accessibility DoD

Links and buttons with descriptive names, status conveyed by text and not only color, logical
heading order, visible focus.
