# WLMOUSE Reference Specification
Classify patterns as `ADOPT`, `ADAPT`, `REJECT`.

| Pattern | Decision | Translation |
|---|---|---|
| Product-dominant composition | ADOPT | Large premium media |
| Technical specs as marketing | ADOPT | Category-aware visual stats |
| Editorial long-form PDP | ADOPT | Admin-driven Product Story |
| Sparse premium shell | ADOPT | Restrained original UI |
| Manufacturer IA | ADAPT | Categories + brands + search + filters |
| Heavy media | ADAPT | Responsive optimized pipeline |
| Motion | ADAPT | Subtle/reduced-motion aware |
| WLMOUSE identity/assets/copy | REJECT | Original Gamer Perú identity |
| Pixel-for-pixel layouts | REJECT | Original compositions |

Benchmark navigation, home, cards, collections, PDP, cart, search, mobile, typography rhythm, motion and trust. Adapt trust for Peru: delivery, warranty, support, stock and Yape/Plin verification.
