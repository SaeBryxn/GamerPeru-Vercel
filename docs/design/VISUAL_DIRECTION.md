# Visual Direction

## North Star
Premium, clean, technological, editorial, product-first.

## Design Authority
- **Canonical Design Language**: [`GAMER_PERU_DESIGN_LANGUAGE.md`](./GAMER_PERU_DESIGN_LANGUAGE.md) (established in GP-002) is the canonical visual authority, design token definition, and component specification for Gamer Perú.
- **Reference Benchmark**: [`WLMOUSE_REFERENCE_SPEC.md`](./WLMOUSE_REFERENCE_SPEC.md) (GP-001) serves strictly as non-binding benchmark research that informed quality standards, whitespace, large media, and technical storytelling principles.

## Core Visual Guardrails
- **No Clones**: Never copy WLMOUSE code, brand identity, assets, or distinctive compositions.
- **No RGB Clichés**: Avoid generic RGB overload, glowing neon borders, and template clutter.
- **Product Dominance**: Hardware industrial design, metallic/matte finishes, and structural engineering remain visually dominant.
- **Dual-Surface Expression**: Expansive editorial Storefront paired with a compact, data-dense Admin interface.
- **SEO & Performance Integrity**: All text must remain machine-readable semantic HTML; image containers must prevent layout shifts; media loading must be viewport-critical.
- **Quality Gate**: A functional feature that regresses to a generic template UI is not complete.
